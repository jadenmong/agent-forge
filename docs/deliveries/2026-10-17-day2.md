## 3. 核心架构决策

1. **执行权属于 Runtime。** OpenAI SDK 处理 HTTP，MCP SDK 处理协议；模型只提出调用，Registry 再次检查 allowlist/Schema/权限后分派。
2. **Responses 有序重放。** function_call、reasoning encrypted_content 和 function_call_output 按协议保留，call_id 关联结果；不把它们压成普通聊天消息，不存隐藏推理原文。
3. **外部错误有限失败。** 关闭供应商自动重试；拒绝、未完成、非法参数、无续传状态、429/鉴权/网络/MCP 超时断连都有安全原因码，不无限重试。
4. **MCP 目标固定。** 只启动源码确定的本机模块，发现两个名字明确的只读工具，每次连接自己管理生命周期，避免跨请求共享 SDK 取消作用域。
5. **HTTP 是语言无关边界。** UI、curl 和其他语言客户端调用同一 REST/JSON/OpenAPI，不提供其他语言 Runtime。
6. **后台任务仅属于当前进程。** 有强引用和正常退出清理，重启丢失状态；最大四个活动 Run，不把它描述为可靠队列。

替代方案和代价见 [DECISIONS D008–D011](../DECISIONS.md)：previous_response_id/provider store、持久客户端和队列等未在本次增加。

## 7. 五个面试追问与参考答案

1. **SDK 和自研 Runtime 的边界？** SDK 负责模型 HTTP/MCP 协议；Runtime 控制 model/tool 循环、权限、限额、失败和状态，不使用外部 Runner。
2. **Responses 为什么保留 reasoning 项？** 工具续传依赖协议上下文；按顺序保留加密状态和 call_id 关联，store=false 不等于账户 ZDR。隐藏原文不进入状态接口或事件。
3. **MCP 为什么必须真实调用？** import 无法证明协议、返回结构和生命周期正确；本次实际发现并调用后才发现 dict 结构化问题，修复后有 stdio/断连/超时测试和 UI 证据。
4. **为什么后台 Run 不等于队列？** 当前任务只由一个 asyncio 进程持有，无持久化、租约或跨进程协调；重启丢失，不承诺恢复。
5. **如何描述跨语言与测试成绩？** curl 和 React 调同一 HTTP API 证明外部语言可接入，不是多语言 Runtime。107 项是控制/协议回归，Live 未测，不能写成真实模型准确率。

候选人应按实际参与记录说明需求、决策、审核、验收和讲解；Codex 执行代码实现。
